# Design Philosophy

Design for usability first.

Avoid decorative design decisions that do not improve clarity or usability.

Prioritize:

- clarity
- spacing
- hierarchy
- readability
- consistency
- accessibility

---

# Visual Style

Use a minimal modern aesthetic.

Avoid:

- excessive gradients
- glassmorphism everywhere
- oversized shadows
- excessive borders
- cluttered layouts
- too many colors
- overly rounded components
- flashy animations

Prefer:

- whitespace
- subtle contrast
- clean typography
- restrained color usage
- simple layouts
- consistent spacing

---

# Layout Rules

Use spacing to create hierarchy.

Prefer:

- consistent padding
- predictable grid systems
- aligned content
- visual balance

Avoid cramped layouts.

---

# Typography

Typography should create hierarchy naturally.

Rules:

- limit font sizes
- avoid random weights
- use consistent line heights
- prefer readable text over stylish text

Avoid giant hero text unless justified.

---

# Components

Components should feel consistent across the app.

Rules:

- same border radius system
- same spacing scale
- same interaction patterns
- same button behavior

Avoid creating unique styles for every section.

---

# Colors

Use restrained color palettes.

Prefer:

- neutral backgrounds
- 1 primary accent color
- semantic success/warning/error colors

Avoid rainbow UIs.

---

# Animations

Animations should support UX, not distract from it.

Prefer:

- subtle transitions
- fast interactions
- meaningful motion

Avoid:

- bouncing animations
- excessive motion
- delayed interactions

---

# Mobile Design

Design mobile-first.

Ensure:

- proper tap targets
- responsive layouts
- readable font sizes
- clean stacking behavior

---

# Accessibility

Accessibility is mandatory.

Ensure:

- sufficient contrast
- keyboard accessibility
- visible focus states
- semantic structure

---

# Product Thinking

Design should solve user problems efficiently.

Avoid adding sections, cards, charts, or UI elements unless they provide actual value.

Every UI element should justify its existence.

---

# Final Rule

Prefer clean and boring over flashy and inconsistent.
